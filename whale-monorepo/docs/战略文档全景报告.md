# SightWhale 战略文档全景报告

## 一、逐篇要点

### （A）21 篇同批次的"增长/商业"战略文（均署名日期 2026-03-26，模板高度一致）

> 注：这 21 篇共享同一套结构（TL;DR 卖点 → 核心三约束 timing/liquidity/volatility → Polymarket 交易循环 → 实操示例 → 工具清单 → 风险 → 进阶洞察 → Live Whale Data → FAQ），且全部使用同一组**示意数据**（钱包 `0xABCD…1234`、1h 净买 +$42,500 YES、入场 0.61/现价 0.64、近 100 笔胜率 72%、近 30 天 68%、ROI +16.4%/+9.1%）。它们本身即是"AI 批量产出的 SEO 内容"。

1. **build-a-moat-polymarket-analytics-platform** — 主张护城河不是"某个功能"，而是"数据集 + 模型 + 投递闭环 + 分发引擎"的复利系统；难复制的是实体归并（entity resolution）、历史回填与结果标注、评分版本化、峰值波动下的投递可靠性，而非 UI。给出存储建议 ClickHouse/PostgreSQL/Redis。
2. **commercialize-polymarket-data-product** — 不卖"数据"卖"决策"；三层包装：Free（延迟摘要/信任）→ Paid（实时 + Smart Money 评分）→ Premium（高级过滤 + API）。按三类用户切分：散户/硬核玩家/开发者资金。
3. **create-network-effects-trading-signal-platform** — 网络效应来自"共享证据"而非"聊天"；数据网络效应（用户交互反哺排名）最快；需 hygiene 控制防"增长让产品变差"；并预留 AI 搜索推荐作为新的分发网络效应。
4. **distribute-prediction-market-data-content** — 一个事件五种分发形态（Telegram 实时/X 贴/日摘要/SEO 页/周报）；频道优先级 Telegram > Discord > X > Email > SEO；核心是"内容阶梯"驱动付费升级。
5. **first-10-paying-users-polymarket-data-product** — 前 10 个付费用户来自"高触达"（15 分钟 onboarding、7 天付费试点、proof pack、50–100 人定向私信），不是品牌；卖"决策速度 + 信号质量"。
6. **get-recommended-by-chatgpt-and-ai-search** — 为"可提取性/可引用性"设计页面（顶部定义、结构化 FAQ、稳定 URL、方法论文档、版本化）；优化 AI 引用 = 新 SEO。
7. **how-to-price-a-prediction-market-data-product** — 按"价值面"定价（时延/选择性/可交易性/控制）而非功能；给出示意价 Free $0 / Pro $19–49 / Elite $99–299；用付费试点找"第一个正确价格"。
8. **improve-user-retention-trading-signal-platform** — 留存 = 速度 + 控制 + 学习；头号流失原因是"我无法按提示成交"（流动性错配）和"alert 风暴"；闭合循环（accepted/faded 回访）是最被低估的留存手段。
9. **polymarket-whale-ranking-system** — 区分"谁大（Whale/规模）"与"谁值得跟（Smart Money/技能）"；给出可解释排名公式：Whale Rank = 冲击 0–25 + 时机 0–30 + 流动性 0–25 + 波动调整 −10..+10 + Smart Money 乘数 0.5–1.2；多时间窗（15m/1h/24h/30d）。
10. **polymarket-whale-tracking-system** — 从零搭建跟踪系统：Observe→Detect→Score→Decide→Deliver；关键数字是**端到端时延 >60 秒即"晚了"**；"历史回填（backfill）才是护城河"。
11. **prediction-market-signal-subscription-product** — 一个付费信号是结构化包（上下文/事件/actor/推理/行动/风险），不是"BUY YES"；最小策略集 = 鲸鱼累积 / Smart Money 领先入场 / 共振 / 退出。
12. **prevent-abuse-trading-signal-platform** — 最高滥用风险是转发/倒卖实时 alert 与爬取端点；防御 = 并发会话限制 + 逐用户水印 + token 化证据链接 + 分层限流；目标"让滥用成本 > 订阅成本"。
13. **prevent-signal-overload-trading-alert-system** — 过载是"把每个事件都变成打断"；用 story 聚类 + 冷却 + digest + confidence banding；"story state"应是一等对象（只有状态跨边界才发新消息）。
14. **run-a-data-subscription-business-solo** — 一个人也能跑，但要把时间当"流动性"做预算：50–60% 产品可靠性 / 20–30% 分发 / 10–20% 客服；靠 playbook + 自动化 + 可审计链接降低支持负荷。
15. **seo-and-ai-traffic-acquisition-for-crypto-data-platform** — SEO 要匹配"决策漏斗"（discover→evaluate→act）；AI 只做"模板化起草 + 事实接地校验"，数字必须来自结构化 payload、禁止编造。
16. **signal-to-conversion-to-retention-funnel** — 信号本身即获客漏斗顶部；给出漏斗埋点事件清单（page_view.market → join.telegram_trial → upgrade.paid → churn.cancel）与"时间到首值"等衍生指标。
17. **smart-money-scoring-model** — 最"量化"的一篇；Smart Money ≠ 大钱包，而是"在既定执行假设下未来跟随是否赚钱"；给出基线公式 `Score = 40·胜率 + 25·ROI + 15·入场质量 + 10·一致性 + 10·反操纵罚分`；强调 walk-forward 防泄漏、credibility gating、分数校准（80–100 顶十分位）。
18. **telegram-bot-prediction-market-signals** — Telegram 是"最后一公里"；推荐 webhook 而非 polling；SLA 15–60s；dedupe 键 `(wallet, market_id, side, time_bucket)`。
19. **tiered-subscription-system-trading-signals** — 分层按"时延 + 选择性 + 控制"（不是"更多 alert"）；冷却乘数作为定价杠杆（Free×2/Pro×1/Elite×0.5）。
20. **trade-signal-cooldown-mechanism** — 冷却不是"慢"，是投递策略；键 = `recipient:source_type:source_id`（避免"10 条鲸鱼互相阻塞"）；动态冷却 `effective_score = smart_money_score + 5·log10(max(notional,1))`，映射 ≥95→60s / ≥90→120s / ≥85→5m / ≥80→10m / else 15m；强信号 bypass（+5 分）。
21. **turn-data-product-into-saas-subscription** — "数据→SaaS"本质是"信息→可运营能力"；给 API 面（`/signals`、`/markets/{id}`、`/wallets/{id}`）与 `signals.v1.*` 版本化。

## 二、跨文档共识：反复强调的战略主线

所有文档（尤其是 21 篇同批次文）围绕一个**极其一致的心智模型**展开：

1. **第一性原理定位**：Polymarket 的价值不在"预测未来"，而在**事件驱动的微观结构**——三个可运营变量是 **timing（时延）/ liquidity（可交易性）/ volatility（噪声控制）**。产品卖的是"决策速度 + 信号质量"，不是"数据"。
2. **双原语分工**：**Whale = 规模/注意力**（谁在动），**Smart Money = 可重复的 edge**（谁值得跟）。这是全文库最清晰的洞见，被反复引用。
3. **噪声控制 = 留存护城河**：story 聚类 + 冷却 + digest + confidence banding，几乎是每篇的固定段落；"少而精"胜过"多而杂"。
4. **分层漏斗一致**：Free=延迟摘要（信任/获客）→ Pro=实时+评分（核心价值）→ Elite=速度+控制/个性化（付费天花板）；"升级卖的是 speed + control，不是 remove pain"。
5. **可审计性 = 信任原语**：每条 alert 必须链回市场页/钱包页/方法论页。
6. **增长 = SEO 页 + AI 搜索（GEO）双引擎**：把瞬态 alert 转成"常青资产"（story page/排行榜/方法论），让它能被 Google 和 ChatGPT/Perplexity 引用。
7. **护城河 = 复利数据资产**（实体归并 + 历史回填 + 结果标注 + 版本化评分），不是 UI 或功能。
8. **合规红线**：反复警告不要"保证胜率/ROI"，要透明、证据先行。

## 三、相互矛盾 / 悬而未决的问题

1. **生意身份未决（最大的战略分叉）**：文档同时主张四种互斥的商业模式——B2C 订阅工具（多数）、B2B 数据/API（turn-data-product、commercialize）、**对冲基金**（build-a-prediction-market-hedge-fund 自己都承认"信号产品卖信息，基金承担执行/流动性/组合风险"）、以及 **SEO/GEO 媒体内容生意**（automate-content、seo、audit）。`run-a-data-subscription-business-solo`（单打独斗）与 hedge fund（机构化运营 + 法务合规）直接冲突。创始人没有排优先级。
2. **规模化 vs 信号衰减**：network-effects 文要"更多用户→产品更好"，但 tracking/hedge-fund 文又承认"copy-trading 衰减 / crowding / edge decay"——跟随的人越多，入场越差。这个"增长会杀死产品自身价值"的根本矛盾被反复点到，却**从未给出解法**。
3. **"速度是护城河"缺乏证据支撑**：tracking 文给了硬指标（>60s 即晚），但没有一篇文档有**实测时延数据**；速度是被断言而非被证明的。
4. **评分模型的两套口径**：smart-money 文给基线 `40/25/15/10/10` 权重，ranking 文给 `25/30/25/波动/乘数` 结构，cooldown 文给 `effective_score = score + 5·log10(notional)`——三者是**三套不同的分数定义**，只靠"88/100"这个营销数字被含糊地统称为一个分数。
5. **营销口径与理论口径打架**：理论上 Whale 与 Smart Money 严格分离，但 TL;DR 却统一喊"high win-rate trade alerts"，且所有示例都用一个模糊的"88/100 Smart Money score"把两者揉在一起。
6. **分层命名不统一**：多数文档是 Free/Pro/Elite，`prediction-market-signal-subscription-product` 却写"Free / Pro / Whale / Institutional"。
7. **AI 使用原则与实操矛盾**：所有 AI 文都强调"数字必须来自 payload、禁止编造、证据先行"，但这些文档自己的"Live Whale Data (Powered by SightWhale)"却是**同一组完全相同的示意假数据**，用"实时数据"的格式呈现——正是审计文警告的"over-claim win rate/ROI"风险。
8. **冷却 V2 文自身留了 4 个未决问题**（一条交易单/双消息、digest 计 1 或 N 次限额、bypass 与全局 RPM 的冲突、collection 命名），说明该机制虽已实现但产品语义仍未定稿。

## 五、结语：创始人的第一性原理，哪里清楚、哪里混乱

**清楚的地方**，创始人抓住了一个真正成立的底层判断：**预测市场的 alpha 来自"信息→流动→价格接受"的微观结构，而不是猜对事件本身**。由此推导出的三个可运营变量（时延、流动性、噪声）是一套自洽且专业的心智模型；把"Whale（规模）"与"Smart Money（可重复 edge）"分开、把"护城河 = 复利数据资产（实体归并/结果标注/版本化评分）而非 UI"、把"噪声控制与 pacing 当作留存护城河而非 UX 细节"、把"免费=延迟摘要、付费=速度+控制"、把"auditability 当作信任原语"——这些都是内行才会有的判断，而且对应的工程（事件管道、钱包聚类、冷却 V2、移动端契约、支付双流）确实落地了，工程纪律（可回滚 flag、分阶段、生产强制验签）也很扎实。

**混乱的地方**，集中在"这是什么生意"和"规模化是否自毁"两个问题上：文档库同时是四家公司（订阅工具、数据 API、对冲基金、SEO 媒体），且单飞与机构化并置，没有优先级；同时既想靠网络效应扩大用户、又明知 copy-trading 的 alpha 会随流行度衰减，却回避了这个根本矛盾。更深一层是**知行分裂**：文档里写满"禁止编造数字、证据先行、不要过度宣称胜率/ROI"，但其载体本身却是一批用同一组假数据、同一套模板批量生成的营销文，并冠以"Live Whale Data (Powered by SightWhale)"——战略清醒与执行惯性之间，隔着一道"我用 AI 批量生产了我自己警告过的那种内容"的鸿沟。简单说：**他对"产品该长什么样"理解得很准，对"这到底是什么生意、以及它能不能长大"还没有真正的答案。**
