## 五、上线清单（创始人手动执行）

1. **后端（Render）**：部署后自动跑 `alembic upgrade head`（unified entrypoint），验证 `0018` 已应用。
2. **landing（Vercel）**：部署前先 `npx prisma migrate deploy`（需要 DATABASE_URL）创建 `prediction_models` 表；否则预测 API 会优雅回退到中性先验，但建议尽快应用。
3. **Vercel 环境变量**：确认 `NEXT_PUBLIC_WHALE_ENGINE_API_BASE_URL` 指向统一服务 `/whale` 前缀（如 `https://sightwhale.onrender.com/whale`），否则 `/whales` 页面会打空。
4. **GitHub secrets**：`daily-blog.yml` 新增使用 `ADMIN_TOKEN`——在仓库 secrets 里补上。
5. **清理历史污染**（可选）：`python scripts/cleanup_health_trades.py`（先干跑再 `--apply`）。
6. **同步线上博客价格文案**：`python scripts/sync_blog_price_copy.py`（先干跑看影响行数）。
7. **验证**：打开 `/whales`、`/whales/0x94f1…`、`/calibration`、`/api/prediction/model` 各看一眼；`/blog` 抽一篇旧文确认价格一致。

## 六、遗留项（有意未做或需要创始人决策）

- `/whales` 动态钱包页不进 sitemap（数量大、变化快）；后续可对 top-N 生成。
- 博客文章独立 OG 图（审计建议）仍缺——全局共用一张。
- 事件类文章的 Outcome 回访仍是手工流程（未做自动化，避免再加 schema）。
- `rate-limiter.ts` 是内存实现，Vercel 多实例下不是全局限流；量大了换 Upstash Redis。
- 免费层的 Telegram 延迟频道（公众频道广播）未实现，属运营动作。
